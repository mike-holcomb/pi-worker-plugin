# Pi Agents v0.1.0

First release candidate of Pi Agents, an independent MIT-licensed fork of OpenCode Worker Plugin 2.1.0. Plugin, runtime, diagnostics, and MCP identify as `0.1.0`. This document describes the candidate; the release becomes available when its tag and GitHub release are published.

## Changes

- Run owned local worker processes with bundled Pi Durable 1.5.0 and provider dependencies.
- Preserve eleven MCP operations for durable admission, recovery, progress, permissions, immutable evidence, and parent review.
- Support native OpenAI, Anthropic, Google, OpenRouter, and custom OpenAI-compatible model routes, including keyless loopback endpoints.
- Recover exact submissions and pending permissions across reconnects; interrupted effectful calls require fresh approval rather than automatic replay.
- Use independent `pi-agents` names, `PI_AGENTS_*` configuration, and state locations so OpenCode Agents can remain installed.
- Distribute a deterministic, allowlisted plugin ZIP with per-file hashes, SHA-256 checksums, and third-party license notices.

## Install

Once the tag is available, with Node.js `>=24.15 <25` on macOS or Linux:

```bash
codex plugin marketplace add mike-holcomb/pi-worker-plugin --ref v0.1.0
codex plugin add pi-agents@pi-worker-plugin
```

Start a fresh Codex session and select `pi-agents:pi-agents`. No Pi CLI, backend server, Python, or runtime dependency installation is required. Configure project roots and provider/model routes before live execution; see the [installation guide](../../plugins/pi-agents/docs/installation.md).

## Assets

- `pi-agents-v0.1.0.zip`
- `pi-agents-v0.1.0.zip.manifest.json`

Download all three to the same directory. Verify with `sha256sum -c pi-agents-v0.1.0.zip.sha256` on Linux or `shasum -a 256 -c pi-agents-v0.1.0.zip.sha256` on macOS.

## Validation and limits

Automated checks cover durable task contracts, real SQLite reopen, permissions, exact recovery, scoped filesystem tools, local HTTP provider fixtures, and owned worker processes. Packaging checks cover deterministic archives, source-to-executable correspondence, relocated read-only installation, and MCP launch. Twelve inherited evaluation scenarios are validated without model inference.

The initial repository CI passed on macOS and Ubuntu. Release CI tests Node 24.15.0 and 24.22.1 on both platforms before preparing a draft. Record the final tag's CI and marketplace results before publication; prior CI or local ZIP smoke does not establish that tag's installation.

Hosted-provider execution and quality, fresh-client marketplace installation, Linux live-provider behavior, hostile concurrent filesystem modification, and machine power-loss durability need separate evidence. Approved arbitrary shell commands run as the host user and are outside tool-level path containment. See [validation](../../plugins/pi-agents/docs/validation.md).

## Upgrade and rollback

There is no OpenCode database migration. Keep Pi state separate. Reconcile active tasks, stop resolved workers and the daemon, and back up state before replacing a version. Rollback requires the matching runtime and backup; do not open newer schemas with older code. Uninstall does not cancel accepted work or delete evidence.

The upstream Pi API is experimental; dependencies are pinned. Historical OpenCode validation does not certify this runtime.
